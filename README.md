# 작고 소중한 먼지 키우기

작은 먼지들을 만나고, 쓰다듬고, 함께 자라는 수집형 게임입니다.

👉 [게임 플레이하기](https://crazyjamy.github.io/dustgame/)

## 어떻게 키우나요?

- 마우스나 손가락으로 먼지 몸을 살살 쓸어주면 반짝이를 얻어요.
- 반짝이를 먹이면 성장하고, 레벨마다 새로운 이야기가 열려요.
- 재료를 조합하면 그에 맞는 먼지가, 재료를 비우면 랜덤한 먼지가 태어나요.
- 골드로 방과 가구를 업그레이드하고, 먼지가 좋아하는 자리를 찾아주세요.
- 작은 부탁을 들어주면 하루 한 번 반짝이를 나눠줘요.
- 잠깐 쉬고 싶은 먼지는 보관함에 두었다가 다시 꺼내 키울 수 있어요.

## 방에서 옮기기

먼지나 가구를 잠깐 가만히 누르고, 이동 표시가 나타나면 끌어주세요.
손을 먼저 떼면 이동은 취소됩니다. 방 위 ‘배치하기’를 누르면 바로 끌 수 있어요.
배치 중에는 쓰다듬기로 반짝이가 쌓이지 않아요.

## 작은 모험

먼지를 길게 눌러 관리인 루미 앞으로 옮긴 뒤 ‘모험 출발하기’를 눌러주세요.
돌아온 먼지를 맞이하면 재료와 성격이 담긴 작은 엽서를 가져와요.
엽서는 ‘모은 먼지 → 모험 엽서’ 탭에서 다시 읽을 수 있어요.

## 작은 친구들

먼지 50종, 가구 10종, 방 6종과 각자의 이야기를 만나보세요.
미발견 먼지는 실루엣과 조합 힌트로 찾아갈 수 있어요.
모험 엽서 150장과 생활 수첩의 작은 순간도 모아보세요.

## 저장 안내

플레이 기록은 현재 브라우저에 자동 저장됩니다.
다른 기기로 옮기려면 ‘작은 기록’에서 기록을 내보내고 가져와 주세요.
