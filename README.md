# 작고 소중한 먼지 키우기

작은 먼지들을 만나고, 쓰다듬고, 함께 자라는 수집형 게임입니다.

👉 [게임 플레이하기](https://crazyjamy.github.io/dustgame/)

## 어떻게 키우나요?

- 먼지 위에서 커서를 움직여 쓰다듬으면 반짝이를 얻어요.
- 반짝이를 먹이면 성장하고, 레벨마다 새로운 이야기가 열려요.
- 재료를 조합하면 그에 맞는 먼지가 태어나요.
- 재료를 넣지 않으면 랜덤한 먼지를 만나요.
- 먼지를 길게 눌러 루미 앞으로 옮기면 모험을 떠나요.
- 골드로 방과 가구를 업그레이드할 수 있어요.
- 보관함에서 쉬게 했다가 다시 꺼내 키울 수도 있어요.

## 작은 친구들

먼지 50종, 가구 10종, 방 6종을 만나보세요.
각자에게 담긴 작은 이야기도 기다리고 있어요.
