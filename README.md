# 별이 머무는 곳

별을 수집하고 돌보며, 나만의 은하계와 이야기를 만들어가는 편안한 육성·탐험 게임입니다.

**v1.13.35** · 설치나 빌드 없이 정적 파일로 실행합니다.

## 시작하기

1. 작은 빛을 눌러 별을 만나요. 재료를 비우면 무료 랜덤 탄생, 세 재료를 고르면 지정 조합이에요.
2. 같은 종류의 별 두 마리를 합치면 높은 쪽보다 한 레벨 성장해요. 레벨은 서로 달라도 괜찮아요.
3. Lv.2~6에 성장 이야기가 한 편씩 열려요. 쓰다듬기는 반짝이를 모으는 행동이에요.
4. 별빛 임무에서 설치물을 받고, 골드로 강화하며 은하계를 꾸며요.

## 함께 쓴 이야기

별 상세와 선택 카드의 책 아이콘에서 성장 이야기, 엽서, 설치물 추억, 친구 기록을 모아 읽어요. 이전·다음 기록으로 이어 읽을 수 있고, 같은 종류의 별도 개체별 기록을 선택할 수 있어요. 엽서는 같은 종류의 별이 함께 모은 기록으로 표시돼요.

첫 이야기를 읽은 뒤 좋아하는 설치물 곁에 놓거나, 별마다 지정된 항로에서 돌아오거나, 다른 종류의 친구와 가까이 지내면 후일담이 남아요. 후일담을 읽으면 새 대사와 여행 표식이 은하계에 남고, 다섯 이야기를 모두 읽으면 편안한 표정과 완결 대사가 생겨요. 추가 발견을 하지 않아도 성장 본편은 기존 레벨대로 열려요.

천문 설명과 관측 자료는 접힌 **루미의 관측 노트**에서 볼 수 있어요.

## 돌보기와 모험

- 별을 문지르면 반짝이를 모아요. 길게 누르면 배치할 수 있어요.
- 머리 위 골드는 눌러 받아요. 접속 중·미접속 모두 최대 30분 누적하며, 모험·보관 중에는 생산을 쉬어요.
- 루미의 항로에 최대 세 마리를 보내 재료와 엽서를 모아요. 직접 걷는 탐사는 외곽 관측소에서 해요.
- 설치물은 임무 보상으로 얻고, 골드로 Lv.10까지 강화해요. 은하계 확장과 재료·요정 구매에는 반짝이를 써요.

## 저장과 업데이트

같은 주소·브라우저에서는 기존 기록을 이어가요. 저장 키와 내보내기 스키마를 유지했어요. 다른 기기·브라우저·주소로 이동할 때는 작은 기록의 JSON 내보내기·불러오기를 이용해주세요. 테스트 사이트의 기록은 GitHub Pages로 자동 이동하지 않아요.
