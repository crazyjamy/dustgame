# 작고 소중한 별 키우기

별을 만나 합쳐 키우고, 은하계를 꾸미며 작은 우주 이야기를 모으는 브라우저 게임이에요.

[게임 시작하기](https://crazyjamy.github.io/dustgame/)

## v1.13.12

- 반투명 팝업과 공통 탐색 메뉴를 적용했어요. 상단 메뉴에서 골드와 반짝이를 함께 볼 수 있어요.
- 별빛 배경이 탭을 바꿔도 이어지고, 홈의 행성 윤곽은 선명하게 다듬었어요.
- 홈 중앙에서 별을 만날 수 있어요. 탄생 버튼은 행성과 겹치지 않도록 조금 내려갔고, 별과 장비는 행성 위쪽 공간에도 놓을 수 있어요.

## v1.11.0

- 별마다 다른 이름, 모양, 무늬를 만나고 우주 장비로 은하계를 꾸며요.
- 외곽 관측소는 은하계의 **탐사 구역** 버튼으로 들어가요. 중단한 위치에서 이어갈 수 있어요.
- 별을 길게 눌러 **루미** 위에 놓거나 루미의 탐험 수첩에서 별을 골라요. 한 번에 최대 세 마리가 출발하고, 별의 레벨과 인원에 따라 보상이 늘어요.
- 별 이야기와 임무 수첩에서 실제 천문 현상을 살펴볼 수 있어요.

배포 방법은 [DEPLOY.md](DEPLOY.md)를 참고해주세요.
