# 별이 머무는 곳

별을 만나고, 함께 자란 이야기를 읽고, 나만의 은하계를 꾸미는 브라우저 게임이에요.

[게임 플레이](https://crazyjamy.github.io/dustgame/)

## v1.13.81 업데이트

- 별은 우주먼지 → 빛방울 → 별싹 → 아기별 → 별 순서로 자라요. 도감에서 다섯 모습을 볼 수 있어요.
- Lv.1은 작은 원형에 눈만 보이고, 자라면서 입과 고유한 윤곽이 생겨요. Lv.5에서 기존 크기에 도달해요.
- 별 카드 상단에 골드, 상세, 보관, 합치기 버튼을 모았어요. 함께 쓴 이야기는 별 상세에서 읽을 수 있어요.

## v1.13.75 업데이트

- 이야기, 관측 노트, 다음 단서의 글자는 제자리에 두고 빛만 지나가도록 정리했어요.
- 빈자리가 있으면 새 별 버튼이 빛나요. 합치기 팝업과 별 상세 카드도 더 간결해졌어요.
- 골드 아이콘은 받을 수 있는 동안 3초마다 돌아요. 모아는 수령 가능할 때 금빛으로 빛나요.
- 설치물 효과와 중첩 규칙은 설정에서 볼 수 있어요. 도감 필터와 일반 알림 아이콘을 정리했어요.

## v1.13.65 업데이트

- 별 50종의 첫인사, 성장 이야기, 후일담을 일상적인 말투로 다듬었어요.
- 탄생 팝업의 별 그림을 최대 144px로 줄이고 인사말 주변 여백을 정리했어요.

## v1.13.63 업데이트

- 처음 만나는 별이 자기 성격을 담은 짧은 인사를 건네요.
- 첫 이야기를 준비할 때 은하계가 가득 차면, 그 화면에서 잠시 보관할 별을 골라 합치기나 조합으로 이어갈 수 있어요.
- 골드와 반짝이는 숫자가 누른 자리에 잠깐 표시되고, 아이콘이 상단 잔액으로 날아가요.
- 상점과 도감에 투명한 탭·필터를 적용했어요. 별자리 배경과 하단 메뉴 전환, 주요 버튼의 반사 효과를 더했어요.

## 처음 시작하기

1. 솔라와 인사하고 은하계에서 작은 빛을 눌러 다른 별을 만나요. 재료를 고르지 않으면 무료로 랜덤 탄생해요.
2. 같은 종류의 별을 합치면 높은 쪽보다 한 레벨 자라며, Lv.2부터 이야기가 한 편씩 열려요.
3. 별빛 임무에서 설치물을 받고 골드로 강화해요. 루미와 탐험을 떠나 재료와 엽서를 모을 수 있어요.

기록은 이 브라우저에 자동 저장돼요. 기기나 사이트 주소를 바꿀 때는 **작은 기록**에서 내보내기와 불러오기를 사용해요.
