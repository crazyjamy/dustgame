## 처음 세 걸음

1. 방의 작은 빛을 눌러 새 친구를 만나요. 재료 없이 만나면 무료 랜덤 탄생이에요.
2. 같은 종류 두 마리를 만나면 ‘먼지 합치기’를 눌러요. 더 높은 쪽보다 한 레벨 높은 별 한 마리가 남아요. 쓰다듬기는 반짝이만 모아요.
3. 첫 이야기를 읽고 별빛 임무에서 행성 고리를 받아요.

먼지를 누르면 선택돼요. 옮기려면 몸이나 가구를 약 0.7초 가만히 누른 뒤 끌어주세요. ‘배치하기’에서는 바로 끌 수 있어요. 같은 종류의 친구가 빛날 때 그 몸 위에 놓으면 두 마리가 한 마리로 합쳐져 레벨업해요. 놓인 대상의 별명·자리는 유지돼요. 모험은 먼지를 루미 앞으로 옮긴 뒤 출발을 확인해야 떠나요.

## 우리 방에서 할 수 있는 것

- **먼지 50종**: 단서로 그룹·희귀도·정수를 추리해 조합해요. 만난 친구의 조합은 자동으로 기록돼요.
- **성장과 이야기**: 같은 종류 두 마리를 합치면 더 높은 쪽보다 한 레벨 올라요. Lv.2~6에 이야기가 한 편씩 열려요.
- **골드와 가구**: 머리 위 골드를 눌러 받아요. 최대 30분의 완성된 생산분이 쌓여요. 보관함·모험 중에는 생산을 쉬어요. 요정 모아를 사면 한 번에 받을 수 있어요.
- **작은 모험**: 책장 아래 숲·햇살 창가·달빛 다락길에서 다른 재료와 엽서를 가져와요. 먼지마다 다르게 기억한 엽서 150장을 모아보세요.
- **방의 기억**: 먼지 Lv.2, 가구 Lv.2, 모험 귀환으로 첫 방의 기억을 복원하면 별모빌을 받아요.
- **수집 장식**: 작은 이웃들·풀잎 산책·달빛 친구들을 모으면 테마 장식을 받아요.
- **나만의 친구**: 별명을 지어주고 좋아하는 가구 가까이에 놓아주세요. 대표 다섯 친구는 고유한 표정과 몸동작을 보여줘요.

## 직접 걷는 탐험 · 책상 아래

루미를 누르고 ‘책상 아래’에서 함께 갈 먼지를 골라 시작해요. 바닥을 클릭하거나 터치하면 그곳으로 걸어가고, 가까운 공간이 조금씩 보여요. 반짝이는 솜뭉치와 풀잎을 찾아보세요. 지우개 왼쪽에 서서 **밀기**를 누르면 뒤에 숨은 길이 열려요. 안쪽 이슬방울까지 찾았다면 **귀환 지점으로 걷기 → 집으로 귀환**을 눌러 재료를 받아요.

‘나중에 계속’을 눌러 중단해도 루미에서 위치와 발견을 이어갈 수 있어요. 탐험 중인 친구는 방에서 잠시 쉬며 골드를 만들지 않아요. 세 재료와 숨은 길을 모두 찾은 기록은 루미의 ‘책상 아래 귀환 기록’에서 다시 볼 수 있어요.

## 소리와 저장

상단 **작은 기록**에서 처음 안내, 효과음·음량, 움직임 줄이기, 반짝이 장식 효과를 설정해요. 효과음은 처음에는 꺼져 있어요.

게임 기록은 **현재 브라우저와 주소에 자동 저장**돼요. 같은 주소에서 게임 파일을 업데이트하면 기록을 이어갈 수 있어요. 브라우저 데이터를 지우거나 시크릿 창을 닫으면 기록을 잃을 수 있으니, 중요한 기록은 **기록 내보내기**로 JSON 파일을 보관해주세요.

다른 기기·브라우저, 테스트 사이트와 GitHub Pages 사이에서는 **내보내기 → 기록 불러오기**로 옮겨요. 불러오기 전에 내용 요약을 확인하고 적용해요. 이전 버전에서 내보낸 JSON도 지원해요. 불러오기·초기화 전 기록은 최근 한 개를 복구용으로 보관하며 작은 기록에서 되돌릴 수 있어요.

이미 받은 이야기와 엽서는 다시 읽을 수 있어요. 보관함에 쉬게 한 먼지도 꺼내면 이어서 자라요.

버전 1.10.0 · 배포 방법은 [DEPLOY.md](DEPLOY.md)를 참고해주세요.

방을 먼저 볼 수 있도록 퀘스트는 접혀 있어요. 위쪽 생활 수첩에서 일상을 읽고, 방 안 왼쪽 아래 ‘배치하기’로 옮기세요. 오른쪽 아래에서 방의 기억을 열어요. 새 먼지 탄생은 방 안 작은 빛에서 계속할 수 있어요.

## 재화의 쓰임

쓰다듬어 모은 **반짝이**로 조합 재료를 사요. 재료로 원하는 친구를 만나고, 같은 친구 두 마리를 합쳐 키우세요. 방 업그레이드와 요정 모아도 반짝이를 사용해요. 먼지가 모아준 **골드**는 가구 구매·업그레이드에 사용해요.

‘모은 먼지’의 다음 친구 단서는 펼쳐서 확인해요. 상점은 골드와 반짝이 잔액을 함께 보여주며, 각 버튼에 필요한 재화를 표시해요.

선택한 먼지 카드는 짧게 보여요. 취향과 오늘의 부탁은 접힌 줄을 눌러 펼쳐보세요. 부탁 보상이 준비되면 접힌 상태에서도 알려줘요.

## 방을 함께 키워요

방은 100레벨까지, 2마리에서 최대 200마리까지 넓혀요. 방 아이콘을 누르면 현재 레벨·다음 비용·새 이야기를 볼 수 있어요. 구간별 목록은 접혀 있어요. 10레벨마다 이야기를 읽고 보상 장식을 받아 놓거나 넣어둘 수 있어요. 20레벨에는 햇살 창가, 70레벨에는 달빛 다락길 모험이 열려요. 기존에 열린 길은 계속 이용할 수 있어요. 직접 걸어 다니는 맵은 책상 아래에서 플레이해요.

30레벨부터 방에 찾아온 손님을 누르면 정수 1개를 하루 한 번 받아요. 새 손님은 한국 시간 자정에 찾아와요. 100레벨에서는 마지막 이야기와 특별한 은하수 장식을 받아요.

희귀 먼지는 자기 색의 그라데이션으로 은은하게 빛나요. 팝업을 열면 하단 메뉴는 잠시 숨겨지고, 닫으면 다시 나타나요. 기존 기록은 그대로 이어져요.

## 먼지가 흘리는 하루 반짝이 · 1.4.1

방에 있는 먼지가 한국 시간 자정 기준으로 하루에 반짝이 1개를 바닥에 남겨요. 작은 별을 눌러 받으며 쓰다듬기 보상도 그대로 받아요. 새 먼지는 태어난 다음 날부터 남겨요. 기존 기록의 먼지는 업데이트 후 첫 방문부터 받을 수 있어요.

미수령 반짝이는 먼지 한 마리당 한 묶음(기본 1개)만 남아요. 여러 날 접속하지 않아도 밀린 날짜만큼 쌓이지 않아요. 오래된 반짝이를 받은 날에는 다시 떨어뜨리지 않아요. 보관·모험 중에는 새로 남기지 않지만, 이미 바닥에 놓인 것은 이동·보관·합치기 후에도 받을 수 있어요. 위치와 수령 기록은 자동 저장돼요. 배치 중에는 반짝이를 줍지 않아요.

### 1.5.1 조작 수정
- 책상 아래 지우개를 누르거나 밀기 버튼을 누르면 왼쪽까지 걸어간 뒤 밀어요. 다른 바닥을 누르면 예약한 밀기는 취소돼요.
- 모바일 상단의 먼지 로고를 숨겼어요. 생활 수첩과 재화는 그대로 사용할 수 있어요.

### 1.5.2 모바일 메뉴 위치
- 생활 수첩 아이콘을 반짝이 오른쪽, 설정 버튼 바로 앞으로 옮겼어요. PC 배치는 유지해요.

### 1.5.3 상단 메뉴 순서
- PC와 모바일 모두 반짝이와 설정 사이에 생활 수첩이 있어요.

### 1.6.0 넓어진 먼지의 방
- 먼지를 누르면 방 위의 작은 카드에서 레벨, 골드, 합치기, 이야기, 보관 버튼을 볼 수 있어요. 빈 바닥이나 닫기 버튼으로 카드를 닫아요.

### 1.7.0 방 전체 화면과 퀘스트 요정
- 방을 화면 양옆까지 넓혔어요. 방 위쪽의 보라색 요정을 누르면 다음 퀘스트와 보상을 확인할 수 있어요.

### 1.7.1 스크롤 없는 방
- 방이 상단 메뉴와 하단 메뉴 사이를 채워요. 모바일에서는 퀘스트 요정 아이콘만 표시해요.

### 1.7.2 화면 끝까지 이어지는 방
- 방 배경이 하단 메뉴 뒤와 화면 맨 아래까지 이어져요.

### 1.7.3 새로고침과 PC 팝업
- 모바일 방의 빈 곳을 아래로 당겼다 놓거나, 설정에서 게임 새로고침을 눌러 다시 열 수 있어요.
- PC의 먼지 정보와 퀘스트 안내 팝업을 넓혔어요.

### 1.8.0 별의 은하계
- 기존 방을 은하계로 바꾸고, 수집한 친구를 별로 표현했어요. 기존 저장 기록에서 이어서 플레이할 수 있어요.

### 1.8.1 은하계 디자인
- 도감, 상점, 보관함과 팝업을 은하계 색상으로 맞추고 가구의 색과 장식을 바꿨어요.

### 1.8.2 우주 아이템과 화면 대비
- 우주 장비와 천체를 모티프로 꾸미기 아이템 20종을 새로 그렸어요. 화면의 글자, 카드 경계, 버튼 대비를 높였어요.

### 1.8.3 팝업과 퀘스트 대비
- 퀘스트의 진행 상태, 비용, 보상과 조합·모험·기록 팝업의 글자와 배경을 은하계 색상으로 정리했어요.

### 1.8.4 별 이름과 은하계 색상

별 50종 기본 이름을 우주 테마로 바꾸고, 도감 단서와 미발견 카드, 퀘스트 안내 요정의 색 대비를 정리했어요.

### 1.8.5 별 상세와 조작 상태의 색상

별 상세의 조합 재료와 보유 목록, 도감과 상점 버튼을 은하계 색상으로 맞췄어요. 성장 모습에는 해당 레벨을 표시해요.

### 1.8.7 외곽 관측소와 별빛 임무

직접 탐험 지도를 외곽 관측소로 바꾸고, 루미의 파견 항로와 퀘스트 문구에 우주 테마를 적용했어요. 성장과 골드 안내, 취향, 생활 수첩, 은하계 성장 지도의 대비도 개선했어요.

### 1.8.8 태그와 테두리 색상

모험 보상 태그를 짙은 보라색으로 맞추고, 엽서·가구 카드와 표의 테두리를 차분하게 정리했어요.

### 1.8.9 실제 하늘을 담은 이야기

별 50종의 성장 이야기 250편과 은하계 성장 이야기, 첫 은하계의 기억에 실제 별자리와 천문 현상을 담았어요. 별 이야기에서 관측 주제와 참고 자료를 볼 수 있어요.

### 1.9.0 은하계 UI 색상 토큰

시작 안내와 상점의 재화 표시를 정리했어요. 공통 UI는 라벤더, 골드, 어두운 배경과 상태 색을 역할별로 사용해요. [색상 토큰 표](COLOR-TOKENS.md)에서 값을 확인할 수 있어요.

- 하단 메뉴 아래로 은하계 배경을 이어주고, 행성 고리의 앞뒤를 나누었어요.

### 1.9.2 은하계 가독성

- 글자 크기를 공통 토큰으로 정리하고, 상단 메뉴 뒤까지 은하계 배경을 연결했어요.
- 행성 고리를 온전한 타원으로 그렸고, 골드 말풍선의 밝기를 낮췄어요. 새 별 버튼은 은하계에 별이 없을 때 빛나요.

### 1.9.3 별 실루엣과 반투명 UI

- 상단 메뉴와 도감 요약의 가로선을 빼고, 하단 메뉴와 수집 단서 카드에 반투명 효과를 더했어요.
- 별들의 실루엣을 네모·원·삼각형 등으로 다양하게 그리고, 실루엣마다 점·띠·물결 등의 무늬를 배치했어요.

### 1.9.4 이야기 팝업 정리

- 은하계 기억, 별 이야기, 별 상세에서 겹쳐 보이는 배경과 구분선을 덜어냈어요.

### 1.10.0 루미의 별지도

- 별빛 임무와 은하계 기억에 천문 관측 노트를 추가하고, 솔라 등 일부 별의 첫 이야기를 다시 썼어요.
- 모바일 골드 표시를 동전으로 간소화했어요. 골드 생산량은 기존 계산값의 3분의 1을 올림하며, 보유한 골드는 유지해요.
